# Архитектура

Крейт `lumen` (cdylib + lib), сборка через nih-plug (CLAP, VST3) и nih_plug_egui. Один бандл экспортирует два плагина: синтезатор `Lumen` и эффект `Lumen Strings`.

| Модуль | Роль |
|---|---|
| `lib.rs` | Плагин, выделение голосов (poly/mono/legato, glide), цикл по блокам (32 сэмпла), тракт, `Shared` для GUI |
| `params.rs` | Все параметры; каждая ручка — непрерывный `FloatParam` (enum только для селекторов) |
| `wavetable.rs` | 64 кадра x 11 mip-уровней, строится IFFT при старте, не перестраивается в аудиопотоке |
| `voice.rs` | Осцилляторы (дробный унисон), фильтр, огибающие, вариации на ноту, вызов ресонатора |
| `filter.rs` | TPT state-variable фильтр с плавным морфом LP-BP-HP и мягкой сатурацией |
| `resonator.rs` | Ресонатор на голос: waveguide-пэлк и модальные струна/мембрана/пластина |
| `body.rs` | Шина резонанса деревянного корпуса (10 фиксированных мод, стерео-расстройка) |
| `granular.rs` | Живой гранулятор на кольцевом буфере: freeze, reverse, гармонические интервалы |
| `fx.rs` | Chorus, ping-pong delay, 8-линейный FDN-реверб |
| `chaos.rs` | Органичный дрейф: Орнштейн–Уленбек + розовый Voss-McCartney + Perlin; только массивы фиксированного размера |
| `evolver.rs` | Случайное блуждание Catmull-Rom для Evolve |
| `midi.rs` | Чистая MIDI-логика: декодирование энкодеров, шаг по скорости, 14-бит pickup, автодетект Learn, пружинная инерция |
| `bridge.rs` | Связывает MIDI-движок с параметрами; lock-free зеркало состояния для GUI; сохранение привязок |
| `gui.rs` | egui-редактор синтезатора и MIDI-меню (физика ручек в `widgets.rs`) |
| `presets.rs` | Заводские пресеты и Randomize |
| `strings.rs` | Эффект `LumenStrings`: параметры, входной каскад (drive, touch, skin), тракт, общие метры |
| `sympathetic.rs` | 16 настроенных струн (гребёнки с обратной связью) и таблицы ладов, плюс банк Sub Bass из 8 струн на 1-3 октавы ниже с входом через сдвиг питча вниз |
| `strings_gui.rs` | Редактор эффекта на базе `widgets.rs` |
| `strings_presets.rs` | Заводские пресеты эффекта и список пресетов с постоянным удалением (`~/Library/Application Support/Lumen/strings_deleted_presets.txt`) |
| `resonator/` | Отдельный крейт воркспейса `lumen-resonator`: плагин только с резонатором, использует `sympathetic.rs`, `filter.rs`, `widgets.rs` через `#[path]`; свои параметры, GUI, пресеты и `bank.rs` на 100 пресетов |
| `strings_bank.rs` | 100 сгенерированных пресетов (семейство Cup Bass) |
| `widgets.rs` | Общая тема GUI, аналоговая ручка, секции, селекторы, метры |
| `packgen/mod.rs` | Офлайн-драйвер сэмпл-пака: манифест кита, запись WAV, фоновая задача с прогрессом, анализ из CLI |
| `packgen/kit.rs` | 33 голоса кита как таблицы параметров (бочки, снейры, хэты, перкуссия, басы, пэды, арпеджио, клавиши, текстуры) |
| `packgen/engine.rs` | Офлайн-движок рендера: структура `Patch` (значения ручек) поверх тех же модулей `voice`/`fx`/`body`/`granular` без параметров nih-plug |
| `packgen/groove.rs` | Демо-грув 128 BPM / A phrygian, сетка 1/16, отдельный стем на слой |
| `packgen/variant.rs` | Генератор вариантов по сиду: архетип (пул голосов + баланс эффектов), тембральный характер, форма на 16 тактов из секций, темп, тональность, свинг, блуждание по аккордам, паттерны по секциям, джиттер параметров, линии автоматизации, глубина сайдчейна |
| `packgen/taste.rs` | Учит, какие миксы оставили, а какие удалили (по `mixes/index.json` и диску), и оценивает кандидатов по этому |
| `packgen/score.rs` | Контракт `--score`: рендер внешней JSON-партитуры (слои, ноты, автоматизация) в стемы и микс для других программ |
| `packgen/synth.rs` | Планировщик событий: сэмпл-точный рендер отдельного голоса и многослойных партий |
| `packgen/wav.rs` | Запись 24-битного стерео WAV, обрезка хвоста, фейды, нормализация по пику, огибающая приглушения от бочки, мастер-фильтр и склейка, спектральная статистика |
| `packgen/mp3.rs` | MP3 320 kbps рядом с WAV через ffmpeg |
| `src/bin/lumen_kit.rs` | CLI `lumen-kit`: рендер пака или анализ готовой папки |

## Правила реального времени

Никаких аллокаций, локов и блокирующих вызовов в `process`. Буферы выделяются в `initialize`. GUI общается с
аудиопотоком только через атомики (`Shared`, `MidiShared`); сохраняемые привязки MIDI читаются через `try_lock`.

## Рендер сэмпл-пака

`packgen` рендерит аудио офлайн, вне аудиопотока: кнопка в GUI и бинарь `lumen-kit` поднимают фоновый поток,
создают собственный `Engine`, пишут WAV и отдают прогресс через атомики.
Движок читает структуру `Patch` вместо параметров nih-plug (параметры нельзя записать без хостового
`GuiContext`), но использует те же модули `voice`, `filter`, `resonator`, `body`, `granular`, `fx` и `chaos`,
поэтому сэмплы звучат так же, как играет плагин.

## Путь MIDI к параметру

CC-событие -> `Bridge::on_cc` -> `Engine` (аккумулятор f64, оценка скорости по сэмпл-точным меткам времени) ->
критически демпфированная пружина на блок -> `Bridge::eff` подменяет значение хоста для привязанного `FloatParam`,
пока значение хоста не изменится. Сам параметр хоста из аудиопотока не пишется.
