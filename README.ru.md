# Lumen

Бесплатный wavetable-синтезатор (CLAP + VST3) для organic downtempo и эмбиента на Rust с nih-plug.

## Сборка

```
cargo xtask bundle lumen --release
cp -R target/bundled/lumen.vst3 ~/Library/Audio/Plug-Ins/VST3/
cp -R target/bundled/lumen.clap ~/Library/Audio/Plug-Ins/CLAP/
```

Standalone для разработки: `cargo run --release --features standalone --bin lumen-standalone`.

## Тракт

Два wavetable-осциллятора (mip-карты, дробный унисон, плавный морф) + саб + шум
-> морфящийся SVF-фильтр (LP-BP-HP) -> ресонатор на голос (waveguide-пэлк, модальные струна, мембрана, пластина)
-> шина «деревянный корпус» -> гранулярное облако (freeze, гармонические интервалы) -> chorus -> ping-pong delay -> FDN-реверб.

## Органика

- Макро Organic: случайные отклонения каждой ноты (высота, срез, таблица, уровень), медленный дрейф на голос.
- Макро Chaos: трёхслойный дрейф (Орнштейн–Уленбек, розовый 1/f, Perlin) на таблицу, морф, срез, высоту и позицию/размер зёрен.
- Evolve: автономное плавное блуждание позиции таблицы, морфа и среза.

## Управление

Все ручки непрерывные. У ручки в GUI есть люфт и инерция (пружина с массой, бросок).
Перетаскивание: обычное; Shift: точно; Alt/Cmd: сверхточно; колесо: подстройка; двойной клик: сброс; правый клик: MIDI learn.

## MIDI

Правый клик по ручке, «MIDI learn», двигаете контроллер. Тип энкодера определяется автоматически по первым сообщениям
(абсолютный потенциометр, two's complement, offset-64, sign-magnitude); поддерживаются 14-битные пары CC (CC n + n+32) с подхватом.
Скорость кручения задаёт шаг на тик по логарифмической кривой от `MIDI Fine Step` (по умолчанию 1e-8 диапазона) до
`1/MIDI Coarse Ticks`; значения копятся в f64 и идут через критически демпфированную пружину (`MIDI Inertia`).
Привязанный параметр следует за MIDI, пока хост или GUI его не изменит.

## Тесты

`cargo test` покрывает уровни wavetable, строй и затухание waveguide, устойчивость ресонатора, питч/freeze гранулятора,
отклик корпуса, статистику хаоса, поведение MIDI-движка, валидность пресетов и сквозной MIDI learn.
