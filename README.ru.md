# Lumen

Бесплатный wavetable-синтезатор (CLAP + VST3) для organic downtempo и эмбиента на Rust с nih-plug.

## Сборка

```
cargo xtask bundle lumen --release
cp -R target/bundled/lumen.vst3 ~/Library/Audio/Plug-Ins/VST3/
cp -R target/bundled/lumen.clap ~/Library/Audio/Plug-Ins/CLAP/
```

Standalone для разработки: `cargo standalone` (алиас для
`cargo run --release --features standalone --bin lumen-standalone --`). Без флага
`--features standalone` цель не собирается, поэтому используй алиас. Если стоит JACK и окно
не появляется — задай бэкенд явно: `cargo standalone -- -b core-audio`.

## Тракт

Два wavetable-осциллятора (mip-карты, дробный унисон, плавный морф) + саб + шум
-> морфящийся SVF-фильтр (LP-BP-HP) -> ресонатор на голос (waveguide-пэлк, модальные струна, мембрана, пластина)
-> шина «деревянный корпус» -> гранулярное облако (freeze, гармонические интервалы) -> chorus -> ping-pong delay -> FDN-реверб.

## Органика

- Макро Organic: случайные отклонения каждой ноты (высота, срез, таблица, уровень), медленный дрейф на голос.
- Макро Chaos: трёхслойный дрейф (Орнштейн–Уленбек, розовый 1/f, Perlin) на таблицу, морф, срез, высоту и позицию/размер зёрен.
- Evolve: автономное плавное блуждание позиции таблицы, морфа и среза.

## Управление

Все ручки непрерывные. У ручки в GUI есть люфт и инерция (пружина с массой, бросок).
Перетаскивание: обычное; Shift: точно; Alt/Cmd: сверхточно; колесо: подстройка; двойной клик: сброс; правый клик: MIDI learn.

## MIDI

Правый клик по ручке, «MIDI learn», двигаете контроллер. Тип энкодера определяется автоматически по первым сообщениям
(абсолютный потенциометр, two's complement, offset-64, sign-magnitude); поддерживаются 14-битные пары CC (CC n + n+32) с подхватом.
Скорость кручения задаёт шаг на тик по логарифмической кривой от `MIDI Fine Step` (по умолчанию 1e-8 диапазона) до
`1/MIDI Coarse Ticks`; значения копятся в f64 и идут через критически демпфированную пружину (`MIDI Inertia`).
Привязанный параметр следует за MIDI, пока хост или GUI его не изменит.

## Lumen Strings (эффект)

В том же бандле лежит **Lumen Strings** — аудио-эффект для электрогитары и эрху (стерео вход, стерео выход).

Вход -> ФВЧ -> ADAA tanh-драйв + тон -> touch-фильтр от огибающей -> «кожа» эрху (два полосовых пика около резонанса
кожи питона) -> 16 симпатических струн, настроенных на тонику и лад (Gong, Shang, Jue, Zhi, Yu, натуральный минор,
дорийский, фригийский, квинты) -> деревянный корпус -> гранулярное облако -> chorus -> delay -> FDN-реверб -> Dry/Wet.

- Симпатические струны: настроенные гребёнки с обратной связью и дробной задержкой; сыгранные ноты раскачивают совпадающие струны.
- Sub Bass: второй банк из 8 струн на 1-3 октавы ниже тоники (Sub Drop); вход сдвигается вниз по питчу, поэтому высокий звон (фарфоровая чашка) звучит как бас.
- Пресеты: кнопка "x" рядом с выбором пресета удаляет текущий пресет навсегда (хранится в `~/Library/Application Support/Lumen/strings_deleted_presets.txt`; удалите этот файл, чтобы вернуть все).
- Bloom: влажные слои приглушаются, пока вы играете, и раскрываются в паузах.
- Organic: медленный хаотичный дрейф строя струн, размера корпуса и позиции/размера зёрен.
- Ручки и пресеты используют ту же аналоговую физику ручек, что и синтезатор.

## Lumen Resonator (отдельный плагин)

Отдельный VST3/CLAP в `resonator/`: только симпатические струны и банк Sub Bass, 100 пресетов и удаление пресетов (кнопка "x"; хранится в `~/Library/Application Support/Lumen/resonator_deleted_presets.txt`).
Переиспользует `sympathetic.rs`, `filter.rs` и `widgets.rs` основного крейта через `#[path]`.

```
cargo xtask bundle lumen-resonator --release
cp -R target/bundled/lumen-resonator.vst3 ~/Library/Audio/Plug-Ins/VST3/
cp -R target/bundled/lumen-resonator.clap ~/Library/Audio/Plug-Ins/CLAP/
```

## Генератор сэмпл-пака

Плагин умеет сам писать готовый набор сэмплов: 33 голоса (бочки, снейры, хэты, перкуссия, басы,
пэды, арпеджио, клавиши, текстурные слои) и сведённый демо-грув, офлайн-рендер 48 кГц / 24 бита стерео.

- В плагине: **Output → Sample kit → One-shots / Demo groove / Everything**. Папка выбирается в окне;
  рендер идёт в фоновом потоке и не трогает аудио-поток.
- Из терминала, без DAW:

```
cargo run --release --bin lumen-kit -- --mode all --out "$HOME/Music Projects/Samples/lumen-kit"
cargo run --release --bin lumen-kit -- --analyze "$HOME/Music Projects/Samples/lumen-kit/one-shots"
```

Структура вывода:

```
one-shots/  01-kick-deep.wav … 30-texture-downlifter.wav, kit.json, README.md
groove/     kick.wav snare.wav hats.wav hat-open.wav shaker.wav perc.wav bass.wav pad.wav arp.wav
            mix.wav (сумма тех же стемов, −3 dBFS), groove.json, README.md
```

Каждый файл нормализован по пику под свой тип голоса, края с фейдами, а все стемы грува начинаются
в первом такте на 128 BPM, A phrygian, сетка 1/16 — накладываются друг на друга от 0.0 без выравнивания.
Таблицы кита — `src/packgen/kit.rs`, паттерны грува — `src/packgen/groove.rs`.

### Пачки миксов

`--mixes N` рендерит N *разных* миксов из подряд идущих сидов. Каждый сид выбирает **архетип**
(dub techno / ambient drift / trip hop / broken beat / cinematic / lo-fi house) — он задаёт пул голосов
и баланс эффектов, — а затем строит **форму на 16 тактов** из секций (intro / main / break / drop / outro
в одной из четырёх раскладок), темп (86–134 BPM), тональность (8 тоник × phrygian / dorian / minor /
lydian / pentatonic), свинг, прогрессию из 8 аккордов (аккорд на 2 такта), рисунок барабанов по секциям,
басовую линию и 2-тактовый мотив, плотность и филлы по секциям, джиттер всей цепочки (таблица, срез,
резонанс, драйв, унисон/расстройка, резонатор, корпус, грануляр, хорус/дилей/реверб, огибающие, LFO,
evolve) и 1–3 линии автоматизации на мелодический слой (срез, морф, грануляр, резонатор, таблица,
дилей, режим фильтра). Один сид → байт-в-байт одинаковое аудио, разные сиды → разные звуки.

```
cargo run --release --bin lumen-kit -- --mixes 100 --seed 1
cargo run --release --bin lumen-kit -- --mixes 100 --seed 1 --stems   # оставить стемы на микс
```

Вывод: `mixes/NNN-seed<seed>/mix.wav` (со `--stems` — плюс стемы), `variant.json` на микс и
`mixes/index.json` + `mixes/INDEX.md` с BPM, тональностью, архетипом, формой, голосами и автоматизацией.

### Рендер внешней партитуры

`--score file.json` рендерит ноты из другой программы (так это использует `polymuse`) в стемы и микс:

```json
{"title": "sketch", "bpm": 96, "bars": 16, "seed": 3, "jitter": 0.5,
 "layers": [
   {"name": "Kick", "kit_voice": "kick-deep", "peak_db": -6,
    "events": [{"time": 0.0, "note": 36, "velocity": 0.95, "duration": 0.02}]},
   {"name": "Harmony", "kit_voice": "pad-warm", "events": [
      {"time": 0.0, "note": 57, "velocity": 90, "duration": 3.7}],
    "automation": [{"target": "cutoff", "from": 0.3, "to": 0.9, "curve": 0.3}]}
 ]}
```

`velocity` принимается и в 0–1, и в 0–127. Вывод: `<out>/mix.wav`, `<out>/stems/*.wav`,
`<out>/report.json`. Неизвестный `kit_voice` падает со списком допустимых голосов; список есть
в `kit.json` в папке one-shots.

## Процедурная генерация

Всё, что рендерит генератор, выводится из одного сида, и сид одновременно управляет *музыкальной теорией*,
*звуковым дизайном* и *миксом*:

1. **Вкус** — пачка читает `mixes/index.json` и проверяет, какие папки ещё существуют. Удалённые папки
   считаются отклонёнными миксами, оставшиеся — одобренными. Сглаженная лог-отношение-оценка по архетипу
   и использованным голосам отбрасывает кандидатов, похожих на отклонённых: поэтому после чистки
   новая пачка смещается к тому, что выжило.
2. **Архетип** — один из шести (dub techno, ambient drift, trip hop, broken beat, cinematic, lo-fi house)
   задаёт пул голосов на роль и баланс эффектов (реверб/дилей/хорус/грануляр), с шансом 30–45 % добавить
   лишний голос из широкого пула, чтобы два микса редко делили палитру.
3. **Характер** — один из восьми тембральных смещений (bright, dark, wet, dry, resonant, gritty, detuned,
   grainy) масштабирует срез, резонанс, драйв, посыл в реверб, унисон/расстройку и грануляр на всех слоях.
4. **Форма** — 16 тактов, собранных из секций intro / main / break / drop / outro в одной из четырёх
   раскладок; у каждой секции своя плотность барабанов, филл, текстура и поведение пауз.
5. **Гармония** — блуждание по 8 аккордам (аккорд на 2 такта) внутри лада, с голосоведением по ступеням;
   бас идёт по аккордам с интервалами, а в main/drop входит слой 2-тактового мотива.
6. **Автоматизация** — 1–3 линии на мелодический слой (срез, морф, грануляр, резонатор, таблица, дилей,
   режим фильтра) идут через все 16 тактов, поэтому тембр движется, а не повторяется.
7. **Защита от однообразия** — кандидат принимается, только если набор его голосов отличается от каждого
   уже отрендеренного микса (и внутри пачки) минимум на четыре голоса.
8. **Сайдчейн и мастер-шина** — бочка управляет огибающей приглушения (3.5–6.5 дБ, атака 1–4 мс,
   спад 90–200 мс) для баса, пэда, арпа, клавиш и текстур, поэтому низ качает, а не борется сам с собой.
   Дальше микс проходит высокочастотный фильтр 28 Гц, мягкий клип как склейка и нормализацию по пику
   −1 dBFS — это даёт около −16 LUFS с современным крест-фактором.

Сам кит настроен на современное электронное звучание, а не на восьмидесятые: плюки и малеты почти
потеряли физический резонатор (`arp-pluck`, `bass-pluck`, `music-box`, `bell`), получили расстроенный
унисон, гранулярное размытие и более длинные хвосты дилея/реверба, плюс добавлены три новых голоса —
`arp-stab` (широкий расстроенный стаб), `pad-dark` (тёмный развивающийся пэд) и `texture-air`
(гранулярный шлейф).

Один сид → байт-в-байт одинаковое аудио, поэтому любой микс воспроизводится через `--mixes 1 --seed <n>`.
MP3-копии (320 kbps, ffmpeg) пишутся рядом с WAV по флагу `--mp3` — это сжимает пачку из 100 миксов
с ~1.1 ГБ до ~250 МБ.

## Тесты

`cargo test` покрывает уровни wavetable, строй и затухание waveguide, устойчивость ресонатора, питч/freeze гранулятора,
отклик корпуса, статистику хаоса, поведение MIDI-движка, валидность пресетов и сквозной MIDI learn.
